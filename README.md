# Диалог — простой AI-чат для Vercel

[![CI](https://github.com/Kiselb/llm_chat_simple/actions/workflows/ci.yml/badge.svg)](https://github.com/Kiselb/llm_chat_simple/actions/workflows/ci.yml)

Тестовое приложение на Next.js: регистрация и вход по почте, AI-чат и сохранение истории в локальном хранилище браузера.

## Как хранится информация

- аккаунты, текущая сессия и переписка сохраняются в `localStorage`;
- база данных и отдельный сервер авторизации не используются;
- данные доступны только в том же браузере и на том же домене;
- очистка данных браузера удалит аккаунты и историю;
- такой способ подходит для учебного проекта, но не для production-приложения с ценными пользовательскими данными.

Ключ OpenAI-прокси не попадает в браузер: AI вызывается через серверный маршрут `/api/chat` в Vercel Functions.

## Локальный запуск

1. Установите Node.js 22 и pnpm.
2. Скопируйте `.env.example` в `.env.local`.
3. Заполните переменные прокси.
4. Выполните `pnpm install`.
5. Запустите приложение командой `pnpm dev`.

## Публикация на Vercel

1. Импортируйте репозиторий в Vercel как Next.js-проект.
2. В **Settings → Environment Variables** добавьте:

   - `PROXY_API_API_KEY` — ключ OpenAI-совместимого прокси;
   - `PROXY_API_OPENAI_BASE_URL` — базовый URL прокси, обычно с `/v1`;
   - `PROXY_API_OPENAI_MODEL` — необязательно, по умолчанию `gpt-4o-mini`;
   - `NEXT_PUBLIC_APP_URL` — необязательно, итоговый адрес приложения.

3. Нажмите **Deploy**. Подключать PostgreSQL, Neon, Supabase или другое хранилище не требуется.

Секретные значения не добавляйте в Git. Файлы `.env` и `.env.local` исключены через `.gitignore`.
